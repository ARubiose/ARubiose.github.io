# Skin Juego: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir la tercera skin, **Juego** (dirección «Menú de juego»), siguiendo la receta de `docs/system-design.md` §3.4, con cambios mínimos fuera de su hoja.

**Architecture:** La skin se registra en `skinRegistry` y aporta su hoja (`src/styles/skins/game.css`), sus fuentes, sus adornos en `ui.ts` y su preset de intro. Fuera de la hoja solo cambian tres cosas: la tipografía del nombre del hero y de los titulares pasa a tokens CSS (los valores de Terminal van en `base.css`), el color del rol pasa de una utilidad a la hoja de cada skin, y la cabecera recibe un «nombre corto» para el adorno de Juego.

**Tech Stack:** Astro 7, Tailwind CSS 4 (plugin de Vite), TypeScript, GSAP 3, Vitest, Playwright + axe, pnpm 11, Node 24.

**Spec:** [docs/superpowers/specs/2026-10-03-game-skin-design.md](../specs/2026-10-03-game-skin-design.md). Maquetas: [game-menu-desktop.html](../../design/mockups/game-menu-desktop.html) (línea de tiempo A) y [game-menu-mobile.html](../../design/mockups/game-menu-mobile.html).

## Global Constraints

- Antes de cualquier comando de Node: `source ~/.nvm/nvm.sh && nvm use` (la shell trae Node 18; el proyecto usa Node 24).
- Comandos: `pnpm check`, `pnpm test`, `pnpm test:e2e`, `pnpm test:visual:update`. Los e2e construyen el sitio solos (`playwright.config.ts`); para un solo archivo: `pnpm exec playwright test tests/e2e/<archivo> --project=<proyecto>`.
- Id de la skin `game`; nombre visible «Juego» / «Game»; muestra `#ec4c56`; línea de tiempo `single`.
- Tokens de color exactos de la spec §2: `bg #0f0f13`, `surface #17171d`, `surface-2 #1f1f27`, `line #2a2a33`, `text #ececf1`, `body #cfcfd8`, `muted #9a9aa8`, `accent #ec4c56`, `accent-ink #ffffff`, `warn #f0a83a`.
- Fuentes: Saira Condensed 600/700/800, Geist 400/500, Geist Mono 400/500, por Fontsource, **sin precarga**.
- Ningún componente usa colores ni fuentes concretos; la hoja de la skin va en `@layer components`; las utilidades ganan siempre a la skin.
- Adornos siempre con `aria-hidden="true"`; el contenido real es idéntico en las tres skins.
- **Terminal y Táctico no cambian:** sus 8 capturas de `tests/e2e/visual.spec.ts-snapshots/` deben pasar sin regenerarse en todo momento. Solo se generan las 4 nuevas de Juego.
- JS de la portada ≤ 60 KB comprimido.
- Nombres de archivo en inglés; contenido y comentarios en español. Commits en inglés con la línea `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; identidad git personal (`Arubiose`).
- Tras trabajo de interfaz: capturas a 1280 y 390 px con movimiento reducido, revisadas a ojo contra las maquetas (memoria `ui-verification`); `astro preview --ignore-lock` en un puerto libre y matarlo por PID.

## Review Focus

1. **Foco de teclado en elementos recortados con `clip-path`** (botones, pestañas, enlace activo, selector): el contorno de foco de `base.css` va por fuera (`outline-offset: 3px`) y el `clip-path` lo recortaría; en Juego tiene que verse. Test e2e en la tarea 6 (contorno hacia dentro y de color distinto al fondo del botón).
2. **Nombre largo en el hero** (Saira 800 a 84 px, en mayúsculas): no debe desbordar en 1280 px ni en 390 px. Lo cubre la prueba de desbordamiento horizontal de la batería común al ejecutarse en `desktop-game`/`mobile-game` (tarea 6).
3. **Cambio de skin en caliente a Juego y desde Juego** (tras haber hecho scroll): ningún contenido revelado queda invisible y la intro no se repite. Test e2e en la tarea 6 (variante de la prueba existente que cambia a `game`).
4. **Skin `game` guardada en un navegador sin la skin registrada** (p. ej. una versión antigua en caché): ya lo cubre `resolveSkin`; en la tarea 3 se añade el caso `game` al script de arranque para que la cobertura no dependa solo de Terminal.
5. **Adornos de Juego en las dos lenguas** (`/en/`): todos los textos de Juego existen en inglés y solo se ven los de Juego. Test unitario (tarea 3) y e2e (tarea 6).

```ts
/** Nombre corto de la cabecera de Juego: dos primeras palabras del nombre, en mayúsculas («ÁLVARO RUBIO»). */
export function shortNameFromName(name: string): string {
    return name.trim().split(/\s+/).slice(0, 2).join(" ").toLocaleUpperCase("es");
}

/** Indicativo de Táctico: el nombre corto con « // » entre las palabras («ÁLVARO // RUBIO»). */
export function callsignFromName(name: string): string {
    return shortNameFromName(name).split(" ").join(" // ");
}
```

```ts
/** Skin con la que arranca un proyecto de Playwright («desktop-game» → «game»; sin sufijo, Terminal). */
export function skinOf(projectName: string): Skin {
```
